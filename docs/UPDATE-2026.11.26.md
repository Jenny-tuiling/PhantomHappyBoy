# 2026.11.26 单人修复测试版

完整包，包含所需 PhantomPact 1.7.3 底座、依赖及扩展。保留 [上游来源与感谢](../NOTICE.md)。

## 本次改动

- 默认本地底座：关闭多人模式后，只接收1号选定的 XInput 手柄，屏蔽其他手柄输入，沿用该设备的中心校准与死区。
- 单人手柄启动前需按 A 确认设备。断线时释放输入，保留原槽位，原槽重连后恢复；不自动选择另一只手柄。系统重排手柄槽位时仍需重新绑定，不承诺跨槽硬件识别。
- 单人不启动多人角色生成、AI或多人快捷键。单人输入桥接使用本次进程的标记，拒绝旧会话请求。
- 临时增强从真实的本地玩家控制器判断人数，不再依赖可能残留的四人路由文件。单人对1号、多人对实际加入玩家应用原有锁血＋10倍伤害。仍需手动开启，关闭恢复模块所拥有的效果，重启默认关闭。
- 设置页同步说明和按钮可用条件。

1.7.3稳定底座的脚本与DLL未改；单人输入修复仅在本地底座生效。增强模块为两套底座共用。

## 已验证

- 14组 native 测试通过：包含新增的单人隔离／校准／焦点／断线重连／过期请求，以及原有多人输入、AI意愿、恢复组合键等回归。
- 6组设置页测试通过；增强开关31项检查，启动器59项检查。底座切换检查在游戏关闭后单独完成。
- Lua 模拟：单人桥接只在单人启动；增强在1／2／3／4人下开启、关闭与数值恢复；加载暂停／恢复、旧会话拒绝、残留四人路由不干扰单人。
- 本机已确认单人过滤器加载成功、绑定选定手柄。
- 完整包649项载荷哈希、源码与内层清单一致性通过；两套实际底座可在隔离目录切换。安装夹具8项通过：预检、全新安装、重复安装拦截、改动文件保护、卸载保留游戏、损坏载荷拦截、路径越界拦截和错误游戏版本拦截。

这些结果不等于完整游戏内验收。镜头是否完全停止自转、手柄重连手感，以及单人增强实际受击／伤害效果仍待玩家测试。历史已知问题仍见首页。

## 建议实测顺序

1. 保留四只手柄连接，在本地底座关闭多人，用1号选定手柄进入存档。全部松手，镜头应稳定；分别操作其他手柄，不应干扰。
2. 断开并接回选定手柄，仍控制1号；其他手柄不接管。右摇杆操作和松手应正常。
3. 工具页开启“无敌＋10倍伤害”，状态应显示1／1人生效；再关闭检查效果恢复。死亡／跌落／剧情强制失败不作为可绕过的承诺。
4. 重启确认增强默认关闭。切回2／3／4人模式，测试独立控制、校准、AI开关与召回。

请使用自己的备份存档测试，勿把逻辑模拟测试当作通关保证。
