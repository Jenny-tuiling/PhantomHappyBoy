# PhantomHappyBoy · 小朋友快乐玩mod

**研发测试中｜2026.11.26 单人修复测试版｜非官方｜非商业个人研究与朋友试玩**

《影之刃零》同一台 Windows 电脑、本地 **2–4 人多显示器合作**。基于 **PhantomPact v1.7.3**，由本项目维护设置页、多人输入与校准、AI 托管、归队和相关适配。感谢原作者 **yhsharaf** 及所有上游贡献者。

## 下载后直接安装

### [下载完整项目 ZIP（含源码、程序、依赖和补丁）](https://github.com/Jenny-tuiling/PhantomHappyBoy/archive/refs/heads/main.zip)

也可以点击绿色 **Code → Download ZIP**。本仓库已包含完整 `payload/`：**无需跳转别的项目、无需另外下载旧补丁、无需自己编译，也不需要 GPT。** 你仍需自行拥有支持的游戏。

1. 从 Steam 正常安装并启动过游戏，支持 **Steam build 26367565**。不匹配时安装器会停止。
2. 备份自己的 `ProjectPBZ/Saved/SaveGames`，退出游戏与设备设置页。旧多人版本先用原卸载器卸载。
3. **完整解压** ZIP；打开包含 `Install.cmd` 和 `payload` 的文件夹。
4. 双击 **Install.cmd**，选择包含 `platform` 和 `ProjectPBZ` 的游戏根目录。
5. 安装成功后，桌面自动创建 **小朋友快乐玩mod - 多人设备设置** 快捷方式。
6. Windows 显示器设为扩展显示。设置页开启多人，选 2/3/4 人、键鼠＋手柄或全手柄；各玩家按 **A** 认领设备。摇杆偏移可在卡片顶部归中校准，松开约 4 秒。已绑定手柄断线重连保持分配。
7. 选皮肤、检查设备、启动并进入自己的存档。关闭多人开关则保持单人。本地底座的单人手柄模式也要先在1号卡片按 A 确认手柄；已确认的绑定继续使用。

## 功能与版本

- 独立输入、A 键认领、归中校准、重连保留玩家分配。本地底座的单人模式也隔离未选中的手柄，并沿用选定手柄的校准。
- 2/3/4 号独立 AI 开关和状态显示；中断后继续托管，主动关闭或重启才清除意愿。
- 主机召回、锁定／解锁、队友归队、安全脱困和恢复视角。
- 临时无敌＋10 倍伤害开关：单人对1号生效，多人对当前已加入玩家生效；默认关闭，重启游戏后关闭。
- 魂主角、辰辰、小宝、猪八戒、枫枫五种外观。没有帝皇铠甲、叶瞬光或 Seed。
- 本地测试底座与 **1.7.3＋既有补丁** 可切换，切换前退出游戏。

当前版本在 **2026.11.25 回退基线**上增加单人输入隔离／校准和单人增强开关修复，包含完整 649 项安装载荷及对应源码。无需另下 1.7.3。不会附带作者的存档、绑定、校准或账号信息。

单人输入修复用于默认的**本地底座**；可切换的 **1.7.3 稳定底座保持原样**，不包含这项输入修复。自动测试已通过，本地单人过滤器已确认加载；镜头不串控、断线重连及增强效果仍待完整游戏实测。见[本版改动和验证范围](docs/UPDATE-2026.11.26.md)。

| 玩家 | 功能 | 长按组合 |
|---|---|---|
| 2–4 号各自 | AI 开／关 | L3＋RT，4 秒 |
| 1 号 | 锁定／解锁队友 | L3＋RT，3 秒 |
| 1 号 | 全队召回 | R3＋LT，3 秒 |
| 1 号 | 安全脱困 | L3＋R3，3 秒 |
| 2–4 号各自 | 归队 | L3＋R3，3 秒 |

L3/R3＝按下左右摇杆；LT/RT＝左右扳机。触发后松开再按。键鼠及镜头说明见设置页。

## 已知问题

队友复活可能打断 1 号动作；已撤回的复活输入实验补丁未包含。多人穿行地图光标／选点、庞镇切图、同时喝药归属、部分交互和安全复活落点仍需验证。新皮肤并非所有动作／场景都已验收。
